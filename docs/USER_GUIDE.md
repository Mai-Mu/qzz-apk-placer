# 使用指南

## 准备

- Windows 电脑和一台 Android Pad / PDA。
- 支持数据传输的 USB 线，资源管理器中能打开设备内部存储。
- 一个或多个保存在电脑上的非空 `.apk` 文件。

一次只连接一台目标设备。列表没有固定数量上限，可以为设备配置两个或更多安装包。

## 配置 APK 列表

1. 完整解压 Windows 程序 ZIP，保留 `_internal` 和 `platform-tools` 文件夹，运行 `QzzApkPlacer.exe`。升级时先从旧版托盘退出旧程序。
2. 点击「添加 APK」多选文件，也可分次从不同目录添加。
3. 选中行后可「替换」「移除」「上移」「下移」。顺序也是后续安装顺序。
4. 点击「应用列表」保存并正式生效。设备已连接时立即开始新批次；未连接时等待接入。
5. 接入设备，解锁并选择 USB「文件传输 / MTP」，等待批次结束，逐项检查结果。

编辑中的列表是草稿，不会自动替换当前已应用配置，也不会因增删一项就立即开始任务。草稿与已应用配置不一致时，「立即处理整批」不可用，应先应用列表。

程序记住已应用的列表。升级自单 APK 版本时，原有路径自动成为一项列表。移除全部项目并应用空列表，可以清空配置、暂停自动处理。

同一文件重复添加会忽略重复项。不同目录的 APK 文件名相同时会拒绝同时加入，请先重命名其中一个，避免它们在同一 Download 文件夹内互相覆盖。

## 批次执行顺序

**先尝试传输全部 APK，再按列表顺序安装传输成功的项。**

自动安装关闭时，只传输文件。开启时，一次任务的处理顺序例如：

```text
传输 A → 传输 B → 传输 C → 安装 A → 安装 B → 安装 C
```

单个文件传输失败时继续传其他文件，只安装传输成功的项。单个安装失败时继续安装后续项。列表逐行显示传输、安装及失败详情，顶部显示批次汇总。

已结束的批次（包括部分失败的批次）不会在设备保持连接时无限重复。处理失败原因后，可点击「立即处理整批」重新执行整份已应用的列表。重新接入设备也会开始新批次。

## 自动安装

开关每次启动默认关闭，开启后从下一批任务生效，不会追溯安装已经结束批次的文件。

1. v1.2.1 起，Windows 便携包的 `platform-tools` 已包含官方 ADB 及必需 DLL，无需下载或手动选择工具。
2. 在设备开发者选项中开启 USB 调试，首次连接时允许这台电脑。
3. 开启自动安装后应用列表或点击「立即处理整批」。

程序始终优先使用完整的包内 ADB，升级前保存的其他软件工具路径作为备用，移动整个程序文件夹后仍能自动找到内置工具。点击「配置 ADB」可查看当前使用的路径。若内置文件被删除，请重新完整解压便携包；也可从 [Android 官方页面](https://developer.android.com/tools/releases/platform-tools) 下载并解压后选择备用 `adb.exe`，保留其旁边的 DLL。仅当包内工具不完整时，程序才使用备用路径、Android SDK 或 PATH 中的工具。

已传完但尚未授权时，保留本批次稳定副本，等待授权后继续安装，不重复传文件。重新应用列表或手动开始新批次会取消旧批次尚未完成的项目。

关闭开关会停止本批次尚未开始的安装，传输仍继续；正在进行的安装会先完成。覆盖更新使用 `adb -s <目标序列号> install -r <稳定副本>`，保留应用数据，不自动卸载或强制降级。

签名冲突、版本降级被拒绝、存储不足或设备策略阻止等原因会显示在对应行及记录中，处理后手动重试。无法唯一对应 MTP 与 USB 调试目标时等待，不选择无线设备或模拟器。

## 路径与覆盖规则

任一已应用 APK 被删除、移动、变为空文件或无法读取，都会暂停整批，并取消尚未完成的安装。请替换或移除标红项，重新点击「应用列表」恢复。原路径后来重新出现时也需要重新应用。

源 APK 在原路径更新不会自动触发新批次。正在执行的任务使用开始时制作的稳定副本，避免传输与安装用到不同内容。

目标为内部存储的 `Download`。同名文件先删除再写入，其他文件保留。请等处理完成再拔线；断线可能导致该次写入不完整。程序以提交写入成功并核对文件大小作为传输成功依据。

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 应用列表 | 保存草稿并启用；已连接设备开始新批次 |
| 立即处理整批 | 重新执行已应用列表 |
| 暂停任务 / 恢复任务 | 当前文件结束后暂停，恢复时继续剩余项 |
| 关闭窗口 | 收进系统托盘继续运行 |
| 单击托盘图标 | 恢复窗口 |
| 托盘菜单退出 | 取消等待，待设备调用结束后退出 |
| 传输记录 | 查看各项处理及批次汇总 |

Windows 程序未签名，下载时可核对 Release 附件中的 SHA-256 值。包内仅附带安装所需的 ADB、两个 DLL 及原始第三方声明，不包含完整 Android SDK。

## 设置与日志

目录：`%LOCALAPPDATA%\QzzApkPlacer\`。`settings.json` 保存 APK 列表和 ADB 路径；`app.log` 及滚动备份记录运行状态；`startup-error.log` 在启动异常时生成。

反馈问题可使用 [Issues](https://github.com/Mai-Mu/qzz-apk-placer/issues)，附系统版本、设备型号、复现步骤和对应失败详情。公开日志前请去除客户文件名和本地路径等个人信息。
